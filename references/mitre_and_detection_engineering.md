### B. Atomic Red Team (Red Canary Emulation Framework)
Atomic Red Team provides small, highly portable detection tests mapped to MITRE ATT&CK techniques.
Each technique definition surfaces:
- Technique ID & Sub-technique
- Supported Platforms (Windows, Linux, macOS)
- Required Data Components (e.g. `Process: Process Creation`, `Windows Event ID 4688 / Sysmon 1`)
- Emulation Command Snippet (e.g. `powershell.exe -ExecutionPolicy Bypass -EncodedCommand ...`)
- Cleanup Command (restoring system state after validation)

### C. Sigma Rule Engineering & pySigma Transpilation
Sigma is the open standard detection format for SIEM/EDR log searches:
- `logsource`: Category (`process_creation`, `image_load`, `network_connection`), Product (`windows`, `linux`, `azure`), Service (`security`, `sysmon`, `auditd`).
- `detection`:
  - Selections (`field|contains`, `field|endswith`, `field|re`)
  - Filter exclusions (`filter: field|equals: value`)
  - Condition: Boolean logic (`selection and not filter`)
- Multi-target translation:
  - Splunk SPL: `index=* (Image="*\\powershell.exe" AND CommandLine="*-EncodedCommand*")`
  - Elastic Query DSL: `{"query": {"bool": {"must": [...]}}}`
  - Microsoft Sentinel / Defender KQL: `DeviceProcessEvents | where FileName =~ "powershell.exe" ...`
  - QRadar AQL: `SELECT * FROM events WHERE ...`

## 3. Telemetry Simulation Datasets
The detection lab must provide high-fidelity telemetry representing:
1. **Endpoint Process Telemetry (Sysmon Event ID 1 / Windows Security 4688)**:
   - Malicious encoded PowerShell cradle
   - Legitimate administrative backup script
   - Obfuscated command execution with quoted tokens
2. **Credential Access (Sysmon Event ID 10 / LSASS Access)**:
   - Mimikatz `sekurlsa::logonpasswords` handle access
   - Legitimate antivirus / EDR driver inspection
3. **Defense Evasion (Windows Security Event ID 1102 / Sysmon 11)**:
   - `wevtutil cl Security` log clearing command
   - Normal event log rotation
4. **Network C2 & DNS Tunneling (Sysmon Event ID 3 / 22)**:
   - High-entropy DNS lookup to suspicious C2 domain
   - Normal internal Active Directory DNS query

## 4. Operational Invariants
- Zero layout overflow (table horizontal scrolling contained inside panels with custom scrollbars).
- 100% offline-safe fallback: if the backend Python server is unreachable, all simulation and Navigator features seamlessly execute using client-side TypeScript engines.
- Test coverage: Vitest unit tests for Navigator layer import/export and telemetry simulation; Pytest unit tests for backend endpoints; Playwright visual verification for both pages.
